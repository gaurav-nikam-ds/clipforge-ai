QUICK HELP

How this build works

1. Import a video in Video editor.
2. Add caption lines manually or import an SRT.
3. Select a caption style and canvas ratio.
4. Export to a WebM file using your browser.

Automatic AI transcription and advanced AI editing services are not connected. This build doesn't claim those features are working.
PRIVACY

Local-first preview

Your video is loaded into the current browser tab. This frontend does not upload it to a ClipForge server. Project snapshots store text and settings in this browser only.

Do not treat browser-local storage as encrypted or permanent storage. Clearing site data can delete saved snapshots.
